# Musical-time-machine-msc

This project addresses structural limitation by developing The Time Machine: a content-based recommendation system that maps any modern track to its closest sonic counterpart from a user-specified past decade. Drawing on a combined corpus of 112,358 tracks spanning 1970 to 2024, sourced from two Kaggle datasets, the system applies a k-Nearest Neighbours (k-NN) algorithm across six audio feature dimensions — including valence, energy, acousticness, danceability, loudness, and tempo to identify mathematically similar historical tracks. The artefact is deployed as an interactive Streamlit dashboard and evaluated through three quantitative metrics (Euclidean distance, cosine similarity, and Intra-List Similarity) alongside a qualitative user study with five participants using a Likert scale and the System Usability Scale. Results demonstrate that the system consistently identifies matches 72–88% closer than random baseline selection, achieving a mean cosine similarity of 0.998 across test queries. The project contributes an empirically grounded, psychologically motivated approach to cross-generational music discovery, rooted in the neurocognitive literature on music-evoked autobiographical memory and the reminiscence bump.
